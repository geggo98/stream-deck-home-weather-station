This key always shows the sensor that the focus points at (moved by the Next/Previous Sensor and Station keys and the dial). You choose the value; the Next/Previous Value keys do not change it. Where the sensor does not measure the value, the key says No data and the name of that sensor. The key shows the sensor name from your account (there is no label: it would hide which sensor the key shows). The Next/Previous Sensor keys move this key, but they only visit sensors that report the value the focus is on right now (shown by a Focus display key), not this key's value. The Focus display key follows the value as well.

Only available for measurements that have a trend or a minimum and maximum.
