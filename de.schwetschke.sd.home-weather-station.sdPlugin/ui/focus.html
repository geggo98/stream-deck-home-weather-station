Shows the value that the plugin-wide focus points at: one station, one sensor, one measurement. The navigation keys (next value, next sensor, next station) move the focus, and every focus display, dial and history key that follows the focus repaints. Press this key to fetch the newest data from the cloud (at most once a minute).

The other keys of this group need no settings, they only move the focus or fetch data: Reload fetches the newest cloud data (it cannot make the station measure; at most once a minute), Next / previous value steps through the measurements of the focused sensor, Next / previous sensor shows the same measurement on the next sensor (dimmed when no other sensor reports it), Next / previous station switches the station (dimmed when there is only one). The settings below apply to the focus display.

Only available for measurements that have a trend or a minimum and maximum.

This key always follows the focus, so there is no module or measurement to choose here.

Alert thresholds are not offered here: this key follows the focus, and one number cannot fit every measurement. Thresholds only apply to fixed keys (a measurement key with Follow focus cleared).
