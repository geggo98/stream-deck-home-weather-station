This key needs no settings of its own. It only moves the plugin-wide focus or fetches data:

Next / previous value steps through the measurements of the focused sensor. Next / previous sensor shows the same measurement on the next sensor (dimmed when no other sensor reports it). Next / previous station switches the station (dimmed when there is only one). Reload fetches the newest cloud data (it cannot make the station measure; at most once a minute).

The Focus display, the dial and the History key follow sensor and value; Sensor Focus and measurement keys with Follow focus follow only the sensor. They repaint when the focus moves. Your account is set up in the section below, the same one as on every other key.
